# Rival AI-Incident Definitions

### Do the published definitions of an AI incident count the same things?

The OECD, the EU AI Act, CSET and the AI Incident Database each publish a rule for what counts as an AI incident. This site applies the rival definitions to the same incidents, measures where they disagree, and checks whether the disagreement survives every defensible reading of each definition.
